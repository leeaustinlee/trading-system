# P1.6 RR Root-Cause Diagnosis + Shadow RR Gate

## 目的

P1.6 用 shadow-first 方式回答「最近低 RR trade 為什麼多」以及「若 shadow RR gate 啟用，會少虧還是錯過飆股」。

本階段只新增診斷與模擬，不改 production BUY path，不新增真倉 SELL / auto-order，也不把 shadow gate 結果寫回正式決策。

## API

`GET /api/backtest/diagnosis/rr-root-cause?days=60`

回傳重點：

- `days`：診斷視窗。
- `totalTrades` / `analyzedTrades`：讀取與分析的 `paper_trade` 筆數。
- `lowRrTradeCount` / `lowRrPct`：shadow RR gate 非 `PASS` 的筆數與比例，`DATA_GAP` 會明確保留。
- `avgRiskReward`、`avgEntryToStopPct`、`avgTarget1GainPct`、`avgTarget2GainPct`。
- `rootCauseBuckets`：低 RR 樣本的主要 bucket、count、pct、sample symbols、reason。
- `shadowImpact`：shadow gate 若阻擋低 RR 樣本，forward return 顯示的是避開虧損還是錯過強勢股。
- `dataGaps`：缺資料不補假結論。

## Root Cause Bucket 定義

- `ENTRY_TOO_CHASED`：entry 接近日高，或追價導致 upside/risk 結構偏弱。目前優先用 `dayHigh` proxy。
- `STOP_TOO_WIDE`：entry 到 stop 距離過大，導致 RR 被 risk 端稀釋。
- `TARGET_TOO_CLOSE`：target1/target2 距 entry 太近，reward 端不足。
- `VOLATILITY_MISMATCH`：ATR 尚未接入時，先用 `dayHigh/dayLow` proxy 判斷 stop/target 與日內區間不匹配。
- `MARKET_REGIME_WEAK`：market regime 為弱勢、UNKNOWN 或 DATA_GAP 時仍出現低 RR trade。
- `THEME_WEAK_OR_LOST`：paper trade 題材弱、UNKNOWN、OTHER，或與 repaired candidate trace 比對後仍缺主流題材證據。
- `DATA_GAP`：entry/stop/target 等必要價格欄位缺失，無法得出可信 RR。
- `OTHER`：未命中主要 bucket，需要更多價格計畫、ATR 或決策 trace。

## Shadow RR Gate 安全邊界

`RiskRewardShadowGateService` 是純計算 service：

- `shadowStatus = PASS / FAIL / DATA_GAP`。
- 預設 `minRequiredRr = 1.8`。
- strategy type 包含 `MOMENTUM` 時 `minRequiredRr = 2.0`。
- 回傳 entry、stop、target1、target2 snapshot，方便追資料。

安全限制：

- 不寫入 `position`。
- 不觸發任何真倉 SELL / auto-order。
- 不改 `FinalDecisionService`、正式 BUY path 或 paper trade 建倉語意。
- 若 forward return 不足，shadow impact 回 `INSUFFICIENT_SAMPLE`，不得用少量樣本推論 gate 應正式啟用。

## Interpretation

低 RR 不能直接歸因於「候選品質差」或「價格計畫錯」。要依 bucket 與 shadow impact 分開判斷：

- `STOP_TOO_WIDE` / `TARGET_TOO_CLOSE` 偏向價格計畫問題。
- `ENTRY_TOO_CHASED` 偏向進場價品質與追價問題。
- `MARKET_REGIME_WEAK` 偏向市場環境問題。
- `THEME_WEAK_OR_LOST` 偏向候選品質或 trace 繼承問題。
- `DATA_GAP` 只能代表資料不足，不能補假資料或推論 gate 效果。
- `shadowImpact.missedWinnerCount` 高時代表 gate 可能錯過飆股；`avoidedLoserCount` 高且 sample 足夠時，才支持提高 RR gate 的正式實驗優先級。
